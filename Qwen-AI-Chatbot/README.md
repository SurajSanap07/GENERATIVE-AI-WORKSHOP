# LLM-Powered AI Chatbot using Python and Qwen 2.5

## 📌 Project Overview

This project is a simple LLM-powered AI chatbot developed using Python
and the Qwen2.5-1.5B-Instruct open-source language model.

The chatbot runs in Google Colab using a Tesla T4 GPU and generates
natural-language responses to user questions.

## 🚀 Technologies Used

- Python
- Google Colab
- PyTorch
- Hugging Face Transformers
- Qwen2.5-1.5B-Instruct
- CUDA
- Tesla T4 GPU

## 🧠 Features

- AI-based text generation
- Natural-language conversation
- Conversation history
- Open-source LLM
- GPU-based inference
- No paid LLM API required
